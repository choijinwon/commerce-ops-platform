# Commerce Ops Platform

주문, 재고, 배송, 정산, 고객 데이터를 하나의 화면에서 관리하는 커머스 운영 통합 플랫폼입니다.

단순한 관리자 페이지 클론이 아니라, 여러 판매 채널에서 발생하는 운영 문제를 빠르게 발견하고 처리하는 **실무형 프론트엔드 포트폴리오**를 목표로 만들었습니다.

![Commerce Ops social preview](./public/og.png)

## 주요 기능

- 핵심 지표와 시간대별 주문 흐름을 보여주는 운영 대시보드
- 주문번호, 고객명, 상품명, 판매 채널 통합 검색
- 주문 상태 필터 및 즉시 변경
- 신규 주문 등록과 성공 피드백
- 판매 속도 기반 재고 위험 모니터링
- 결제부터 배송 완료까지 물류 단계 추적
- 채널별 매출, 수수료, 정산 예정액 대사
- 구매 행동 기반 고객 세그먼트 분석
- 데스크톱과 모바일에 대응하는 반응형 UI
- 브라우저 AI 에이전트가 주문 검색과 상태 변경을 수행할 수 있는 WebMCP 도구

## 기술 스택

- React 19, TypeScript
- Next.js 호환 App Router, Vinext, Vite
- Tailwind CSS 4
- shadcn/ui, Base UI, Lucide Icons
- Cloudflare Workers 배포 구성

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 품질 확인

```bash
npm run build
npm run lint
```

## 설계 의도

운영 담당자의 첫 화면에는 소개 문구보다 현재 상태와 즉시 처리할 이슈가 먼저 보여야 합니다. 그래서 첫 뷰포트에 핵심 지표, 주문 흐름, 재고·배송·정산 신호를 배치했습니다.

상세한 구조와 기술적 판단은 [아키텍처 문서](./docs/architecture.md)에 정리했습니다.

> 현재 데이터는 포트폴리오 시연을 위한 샘플이며, 새로 등록하거나 변경한 주문 상태는 브라우저 세션에서만 유지됩니다.
